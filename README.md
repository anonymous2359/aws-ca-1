# FitLife Gym and Fitness Website

## Objective
Build a basic fitness website that presents workout plans, fitness programs, membership plans, and health-related information in a clean and easy-to-read format.

## Features
- Simple and responsive single-page layout
- Navigation links to key sections
- Workout plans for beginner, intermediate, and advanced users
- Fitness programs such as weight loss, muscle gain, yoga, and HIIT
- Membership plans with pricing details
- Health information and wellness tips

## Technologies Used
- HTML5
- CSS3

## Project Structure
- index.html
- style.css
- logo.png

## Setup Instructions
1. Download or clone this project folder.
2. Keep all files in the same directory.
3. Open index.html in any modern web browser.
